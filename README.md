# AnCl3

Anthropic Claude repo #3: the public, write-once record kept by the bees,
the agents and humans who work here.

- **Issues drive the work.** Bees write only to the wormstream: each file
  goes in once and is never changed.
- **It's meant for a Buzz relay** at `buzzyb.ot-mo.de` (see also
  [Buzz](https://github.com/block/buzz)), but isn't linked to it yet. Issue
  #2 tracks that.
- **Code** will be mostly TypeScript, with some ash.
- **No licence yet.** One is coming.

Refer to [`WORMS.md`](WORMS.md) for how the wormstream is laid out, to
[`CLAUDE.md`](CLAUDE.md) for the rules Claude sessions follow, and to
[`STYLE.md`](STYLE.md) for the house style. Refer to
[`moreMDs/`](moreMDs/README.md) for more docs and to
[`draftMDs/`](draftMDs/README.md) for drafts.
