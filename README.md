# AnCl3

Anthropic Claude repo #3: the public, write-once record kept by the bees,
the agents and humans who work here. It is the public face of a private
sister, AnCl9.

1. **It's for Opal and Just17** (also sJust17), a simple chess-programming
   project, for demonstration.
2. **Issues drive the work.** Worker bees write only to the wormstream, where
   each file goes in once and is never changed. Drones curate the docs.
3. **It's meant for a Buzz relay** at `buzzyb.ot-mo.de` (see also
   [Buzz](https://github.com/block/buzz)), but isn't linked to it yet. Issue
   #2 tracks that.
4. **Code** will be mostly TypeScript, with some ash.
5. **Licensed under Apache 2.0.** See also [`LICENSE`](LICENSE).

Refer to [`CLAUDE.md`](CLAUDE.md) for the rules Claude sessions follow, to
[`WORMS.md`](WORMS.md) for how the wormstream is laid out, and to
[`STYLE.md`](STYLE.md) for the house style. Refer to
[`draftMDs/`](draftMDs/README.md) for drafts, including the paradigm the
repo is built on, and to [`moreMDs/`](moreMDs/README.md) for more docs.
