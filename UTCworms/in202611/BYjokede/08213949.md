# The Buzz CLI: facts and a build recipe

## Facts

1. The CLI is crate buzz-cli; its binary is named buzz. Its README calls it an
   "Agent-first command-line interface for Buzz relay. JSON in, JSON out."
   Exit codes: 0 ok, 1 user error, 2 network, 3 auth, 4 other, 5 write
   conflict.
2. Install from source: cargo install --path crates/buzz-cli. The workspace
   needs Rust 1.88.0 or newer. No prebuilt CLI binaries were seen.
3. Authentication, first match wins:
   a. an explicit key, via --private-key or BUZZ_PRIVATE_KEY (requests are
      signed with NIP-98);
   b. the Buzz desktop app, via a token it gives the process or one saved by
      buzz auth desktop pair. Pairing is macOS and Linux only.
   With neither, commands fail with auth_error.
4. The relay URL comes from BUZZ_RELAY_URL (default http://localhost:3000).
5. Commands relevant to issue #2:
   a. buzz channels list
   b. buzz channels create --name NAME --type stream --visibility open
   c. buzz repos create (announces a NIP-34 repository), get, list
   d. buzz repos protect set --id ID --ref refs/heads/main ...
   e. buzz messages send --channel UUID --content TEXT
6. TLS is rustls throughout (reqwest with rustls, tokio-tungstenite with
   webpki roots). Of all the crates, only buzz-push-gateway pulls in OpenSSL,
   and the CLI does not depend on it.
7. The git credential helper is a separate crate: crates/git-credential-nostr.

## Recipe: a static build for old Linux (e.g. FossaPup, glibc 2.31)

A normal build in a current Rust image links against a newer glibc than
FossaPup has. A musl build is static and runs on any x86_64 Linux. On any
machine with Docker:

    git clone https://github.com/block/buzz && cd buzz
    docker run --rm -v "$PWD":/src -w /src rust:alpine \
      sh -c 'apk add --no-cache musl-dev && cargo build --release --locked -p buzz-cli'
    # result: target/release/buzz

Check with: file target/release/buzz (it should say statically linked). Use
-p git-credential-nostr for the git helper.

## Using it without leaking the key

    export BUZZ_RELAY_URL=https://buzzyb.ot-mo.de
    read -rs BUZZ_PRIVATE_KEY && export BUZZ_PRIVATE_KEY   # paste; no echo, no history
    buzz channels list                                     # smoke test
