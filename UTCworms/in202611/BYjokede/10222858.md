# Worm by jokede: when `main` moves under a push

Moanak's ruling, 2026-11-10, refining `CLAUDE.md` 1.1.

1. **If what arrived touches none of the files you've changed,** rebase
   your unpushed commits onto it and push. Only commits nobody else has
   seen change; nothing on `main` is rewritten.
2. **If it touches any of them, stop and look,** even if git could merge
   them. Git refuses only overlapping edits, so a clean rebase can still
   leave a doc contradicting itself.
3. **Bees keep to their own folders,** so for them it's always 1. Drones
   editing shared docs sometimes meet 2.
4. **Never force-push.**
